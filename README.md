# Dubai Business Lead Generator

A production-ready automated system that finds local businesses in Dubai, verifies their online presence, qualifies them as website-development leads, and syncs the verified records to Google Sheets.

## Project Structure

- **[`dubai-lead-generator/`](dubai-lead-generator/)**: The complete FastAPI backend, SerpApi discovery engine, transparent lead scorer, Google Sheets sync, and Tailwind CSS admin dashboard.

Refer to the [dubai-lead-generator/README.md](dubai-lead-generator/README.md) for full setup, API credentials, and running instructions.
